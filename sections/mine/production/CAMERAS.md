# Gullet Mine — Fixed Validation Cameras

Do not move these once formal pixel review begins unless the camera itself is proven invalid and the baseline change is recorded.

| Key | Purpose |
| --- | --- |
| `entry` | Facility approach, preparation bay and mine portal readability |
| `bay_overview` | Overall dispatch-bay composition and circulation |
| `dispatch` | Instruction/workbench/tool cluster |
| `charge_issue` | Charge-issue cabinet, pickup readability and staging logic |
| `main_route` | Downhill rail route, supports, lighting and walkway clarity |
| `reverse_route` | Return-to-facility view and reverse-route readability |
| `dry_cut` | Sector A excavation language and work-face readability |
| `sump` | Pump/sump infrastructure, railing and wet-service access |
| `wet_cut` | Sector B wet mining identity and material separation |
| `collapse` | Sector C oversized-event collapse, blockage and rubble readability |

## Review rules

Use the same camera transform, focal length, resolution, render engine, sampling and colour management when comparing iterations. Review actual pixels for scale, silhouettes, contact, clipping, floating props, rail/gate intersections, route clearance, geological seams, material separation, lighting hierarchy, excessive darkness, signage orientation and detail density.
