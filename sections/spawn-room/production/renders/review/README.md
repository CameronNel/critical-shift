## Review-render purpose

Review renders are deliberately diagnostic. Include views that reveal:
- repeated geometry;
- flat materials;
- weak contact;
- bad scale;
- signage overload;
- lighting sameness;
- empty procedural walls;
- filler clutter.

Compare against the generated Spawn Room reference plates, not against the rejected previous beauty renders.
