# Spawn Room — Critic Protocol

Critics evaluate rendered evidence, not the builder's effort.

Use fresh context where tooling permits.

Each critic receives:
- spawnroom scenery specification;
- relevant global art-direction rules;
- current fixed-camera renders;
- Spawn Room rubric.

Do not provide builder reasoning unless the role is explicitly technical.

Required disciplines:
1. Spatial Readability
2. Stylized Art Direction
3. Materials / Anti-Plastic
4. Lighting / Atmosphere
5. Environmental Storytelling
6. Blender Technical Quality

Each critic returns:
- score for relevant category/categories;
- critical failures;
- top defects ranked by impact;
- concrete correction direction;
- confidence level.

Critics should prefer finding real problems over being agreeable.
