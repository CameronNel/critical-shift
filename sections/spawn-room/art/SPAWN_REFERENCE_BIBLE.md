# Spawn Room Visual Reference Bible

**Status:** mandatory section-specific visual authority  
**Applies to:** hallway, briefing room, locker/suiting room, integrity chamber, radiation checkpoint, doors, furniture, props, materials, lighting, signage and camera review  
**Global authority:** [../../../design/ART_DIRECTION.md](../../../design/ART_DIRECTION.md)

This file exists because verbal instructions such as “make it look stylized” are too easy for an autonomous builder to misread. The Spawn Room has a large set of generated visual plates. **Agents must inspect the plates before modelling, after the validation slice, and again before final review.**

The references are directional. They define composition, scale, silhouette, density, material behavior and visual hierarchy. They are not exact geometry blueprints.

# 2. First-five-seconds test

From the initial player camera, the room must communicate:

- **left:** optional briefing/tutorial;
- **right:** locker and PPE preparation;
- **forward:** operational threshold and danger.

This must work **before** the player reads any text.

If the scene needs labels to explain those three branches, the composition is wrong.

The central gather zone must remain open enough for four players. Dress the edges, not the exact spawn footprint.

# 3. Hallway reference

Use:
- [01_hallway_composition.svg](reference/01_hallway_composition.svg)
- [08_door_wall_architecture.svg](reference/08_door_wall_architecture.svg)
- [09_ceiling_floor_language.svg](reference/09_ceiling_floor_language.svg)
- [14_larger_building_illusion.svg](reference/14_larger_building_illusion.svg)

Target:
- 3.0–3.4 m clear width;
- 3.2–3.8 m ceiling height;
- broad quiet wall areas;
- one modest furniture cluster;
- one grouped information cluster;
- one utility/service cluster;
- thick wall/door construction;
- utilities visibly continuing beyond the playable slice.

Do not place a gadget every metre.

A hallway that looks “finished” only because every wall is occupied has failed.

# 4. Briefing room reference

Use:
- [02_briefing_room.svg](reference/02_briefing_room.svg)
- [18_furniture_reference.svg](reference/18_furniture_reference.svg)
- [19_wall_graphics_portraits.svg](reference/19_wall_graphics_portraits.svg)

Required read:
- screen visible from doorway;
- four primary usable chairs;
- social seating, not military-perfect rows;
- clear circulation;
- screen integrated into facility architecture;
- one official information cluster;
- one human/crew cluster;
- one or two small use-details.

Useful human detail:
- mug;
- training folder;
- clipboard;
- one chair slightly out of line;
- worn armrest;
- crew photo.

Do not create a conference room.

Do not solve the room with six posters and a giant TV.

# 5. Locker / suiting room reference

Use:
- [03_locker_room_overview.svg](reference/03_locker_room_overview.svg)
- [04_suit_bay_anatomy.svg](reference/04_suit_bay_anatomy.svg)
- [05_hazmat_suit_reference.svg](reference/05_hazmat_suit_reference.svg)
- [23_suit_bay_variation.svg](reference/23_suit_bay_variation.svg)

Exactly four primary suit bays are required.

Each bay is a **work station**, not a display pod.

Suggested bay target:
- width: 0.9–1.1 m;
- depth: 0.55–0.70 m;
- height: 2.1–2.3 m;
- shallow recess;
- clear frame;
- top shelf / helmet cradle;
- hooks;
- storage;
- status / checklist zone;
- floor standing area.

Shared bay design:
- same structural family;
- same material family;
- same mounting logic;
- same status-system logic.

Allowed human variation:
- different station ID;
- helmet orientation;
- one note/photo;
- one small personal object;
- one maintenance tag;
- controlled player-colour accent.

Do not vary bays so much that they stop reading as one facility system.

# 6. Hazmat suit reference

Use:
- [05_hazmat_suit_reference.svg](reference/05_hazmat_suit_reference.svg)
- [21_prop_scale_lineup.svg](reference/21_prop_scale_lineup.svg)

The suit must read as **protective clothing**.

Target:
- believable adult proportions;
- simplified anatomy;
- matte fabric volume;
- broad folds at joints;
- clear hood/visor construction;
- believable glove and boot proportions;
- visible seal/closure logic;
- integrated pack / rescue handle;
- one dosimeter/status module;
- limited hoses;
- readable silhouette.

Reject:
- compact/chibi proportions;
- oversized cube helmet;
- huge gloves/boots;
- faceted mannequin;
- armor plating;
- glossy astronaut plastic;
- tactical hard-surface clutter.

The suit can be stylized. It cannot look like a toy.

# 7. Integrity chamber reference

Use:
- [06_integrity_chamber.svg](reference/06_integrity_chamber.svg)
- [22_integrity_chamber_states.svg](reference/22_integrity_chamber_states.svg)

Target footprint:
- 1.8–2.2 m wide;
- 1.8–2.2 m deep;
- 2.6–3.0 m high;
- 1.2 m+ clear circulation around it.

Required form:
- broad structural frame;
- standing platform;
- believable gasket/seal logic;
- partial glass only where useful;
- overhead pressure/scan mechanism;
- one physical controller;
- one compact readout/gauge;
- one door/latch mechanism.

Avoid:
- airport security scanner look;
- transparent sci-fi tube;
- four posts connected by bevelled boxes;
- giant touch screen;
- decorative glowing strips.

State language must combine:
- light;
- movement;
- sound;
- simple gauge/display;
- physical latch/door behavior.

Colour alone is insufficient.

# 8. Radiation checkpoint reference

Use:
- [07_radiation_checkpoint.svg](reference/07_radiation_checkpoint.svg)

It is a **small industrial wall instrument**, not a second hero machine.

Target:
- 0.45–0.70 m wide;
- 0.25–0.40 m deep;
- roughly 0.8–1.2 m body height;
- mounted around chest/eye level;
- readable from 2–4 m.

Use:
- one gauge/readout;
- one physical test/reset control;
- one grille/speaker;
- one sensor/probe area;
- one compact status lamp;
- one small hazard mark.

Do not add a huge kiosk or a screen bigger than the instrument.

---

# 9. Door and wall construction

Use:
- [08_door_wall_architecture.svg](reference/08_door_wall_architecture.svg)

Interior doors:
- 1.2–1.4 m clear width;
- normal adult height around 2.1–2.3 m;
- visible jamb/head construction;
- 100–180 mm apparent wall thickness where plausible.

Operational exit:
- 1.5–1.8 m clear width;
- heavier frame;
- stronger threshold;
- seal logic;
- more authoritative hardware.

A door is not a colored slab inside a bevelled rectangle.

Walls should have:
- broad upper field;
- durable lower-wall zone;
- skirting/base;
- occasional service panel;
- utility routes with plausible continuation.

# 10. Ceiling and floor

Use:
- [09_ceiling_floor_language.svg](reference/09_ceiling_floor_language.svg)

Ceiling:
- repeated practical-light rhythm;
- one or two broad service runs;
- occasional access panel;
- restrained safety fixtures;
- no pipe spaghetti.

Floor:
- large institutional tile/panel system;
- subtle unit variation;
- localized route wear;
- 1–2 replacement tiles/panels;
- threshold strips;
- optional service cover/drain where logical.

The floor tells movement history. The ceiling tells building rhythm.

# 11. Furniture

Use:
- [18_furniture_reference.svg](reference/18_furniture_reference.svg)

Bench:
- 1.6–2.2 m long;
- 0.40–0.50 m deep;
- 0.43–0.47 m seat height.

Chairs:
- believable adult ergonomic proportions;
- simplified tubular/molded structure;
- restrained padded material;
- limited wear at human touch zones.

Do not use tiny classroom furniture or comically thick “stylized” furniture.

---

# 12. Materials and wear

Use:
- [10_material_wear_matrix.svg](reference/10_material_wear_matrix.svg)

Every major material family must remain visually distinct:
- painted metal;
- concrete/plaster;
- restrained plastic;
- rubber;
- PPE fabric;
- floor;
- glass;
- paper/card.

Rule of thumb:
- 80–90% maintained surface;
- 10–20% localized evidence of use/repair/age.

Wear belongs:
- on handles;
- at floor traffic;
- under boots;
- at locker contact;
- near maintenance work;
- at door thresholds;
- around frequently touched controls.

Wear does **not** belong uniformly on every edge.

---

# 13. Colour

Use:
- [20_spawn_colour_palette.svg](reference/20_spawn_colour_palette.svg)

Approximate visual proportions:
- warm wall/structure: 55–65%;
- industrial green/teal: 15–25%;
- charcoal/steel: 8–15%;
- hazard yellow: 3–8%;
- maintenance orange: 0–4%;
- emergency red: 0–2%;
- cool utility blue: 0–4%.

Saturation rises with importance.

Background structure should not compete with:
- player suits;
- interactables;
- hazard states;
- operational exit.

# 14. Lighting

Use:
- [11_lighting_plan.svg](reference/11_lighting_plan.svg)

Hall:
- safe/readable neutral practicals;
- operational threshold can be cooler/harsher.

Locker room:
- suit-bay separation;
- visible contact shadows;
- chamber does not glow like a shrine.

Briefing room:
- modest focal light around tutorial screen;
- screen emission stays localized.

Required:
- visible falloff;
- darker secondary zones;
- contact shadow;
- no global fill that flattens every wall;
- no permanent orange/teal cinematic grade.

# 15. Signage and wall graphics

Use:
- [12_signage_hierarchy.svg](reference/12_signage_hierarchy.svg)
- [19_wall_graphics_portraits.svg](reference/19_wall_graphics_portraits.svg)

Whole Spawn section target:
- one primary directional system;
- 2–4 hazard/procedure signs;
- one grouped shift/notice board;
- 2–4 portraits/institutional images;
- station IDs only where needed.

Delete a sign if its removal does not reduce:
- navigation;
- safety;
- interaction clarity;
- facility character.

Text is not a substitute for shape design.

# 16. Small props

Use:
- [13_small_props_storytelling.svg](reference/13_small_props_storytelling.svg)

Good prop stories:
- mug = break/ownership;
- clipboard = procedure;
- gloves = recent use;
- boots = suiting ritual;
- toolkit = maintenance;
- tape = improvised repair;
- filter = PPE logistics;
- waste bin = daily workplace;
- personal card = individual worker.

Density:
- roughly 3–5 small props per **focal cluster**;
- do not distribute them evenly around the room.

One good cluster is better than ten isolated props.

# 19. Mandatory fixed-camera reference set

At minimum maintain:

- **A — Entry Read:** spawn → left/right/forward composition.
- **B — Hall Forward:** operations exit and radiation checkpoint.
- **C — Locker Entry:** four suit bays + chamber hierarchy.
- **D — Locker Reverse:** circulation, contact, rear surfaces.
- **E — Briefing Entry:** screen and chair read from doorway.
- **F — Material Close:** wall/floor/paint/fabric/glass separation.

At least one camera must be deliberately unflattering.

Do not move cameras to hide defects.

# 20. Automatic visual rejection

Reject the pass immediately if any of these dominate:

- repeated bevelled cuboids;
- every material looks like satin plastic;
- flat even lighting;
- giant kiosk-like machinery;
- excessive signage/screens;
- toy-like PPE;
- floating wall props;
- one prop on every quiet surface;
- random plants used as filler;
- generic sci-fi greebles;
- faceted low-poly presentation;
- photoreal kitbash inconsistency.

Use [16_do_dont_summary.svg](reference/16_do_dont_summary.svg) as the fastest visual sanity check.

Also use:
- [25_validation_slice.svg](reference/25_validation_slice.svg) to define exactly what is allowed in the first style proof;
- [26_modeling_progression.svg](reference/26_modeling_progression.svg) to stop tertiary detail from hiding weak forms;
- [27_wear_placement_map.svg](reference/27_wear_placement_map.svg) to localize wear to real touch/traffic/repair zones.

# 21. Validation slice

Before full-room production, build only:

- one wall section;
- one believable door;
- one suit bay;
- one bench/furniture object;
- one practical light;
- one utility element;
- 3–5 small human-use props.

This slice must prove:
- scale;
- construction;
- geometry language;
- materials;
- wear;
- lighting;
- contact;
- detail density.

The approved slice becomes the canonical kit reference for the rest of the Spawn Room.

---

# 22. Final standard

The Spawn Room is successful when a gameplay screenshot reads as:

> **a believable institutional preparation area inside a huge industrial facility, simplified by a strong game art director.**

It should not read as:
- a browser demo;
- a low-poly pack;
- a futuristic showroom;
- a photoreal UE asset dump.

When in doubt, remove one decorative object, improve one silhouette, improve one material response, and improve one light.
