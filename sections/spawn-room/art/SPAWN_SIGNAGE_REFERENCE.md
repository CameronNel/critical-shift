# Spawn Room Signage Reference

**Visual plates:** [12 signage hierarchy](reference/12_signage_hierarchy.svg), [19 wall graphics](reference/19_wall_graphics_portraits.svg)

The Spawn Room previously suffered from “label every object” syndrome. This file sets an explicit text budget.

## 1. Whole-section budget

Target:
- 1 primary navigation family;
- 2–4 hazard/procedure signs;
- 1 grouped shift/notice board;
- 2–4 portraits / institutional images;
- small station IDs only where needed.

These are targets, not a challenge to hit the maximum.

## 2. Navigation

Examples:
- OPERATIONS →
- BRIEFING
- PPE / SUITING
- room/sector number.

Navigation should be readable from 3–5 m by:
- placement;
- shape;
- color block;
- arrow;
- short text.

## 3. Hazard

Examples:
- RADIATION CONTROL AREA;
- PPE REQUIRED;
- REPORT SEAL DAMAGE;
- emergency route.

One hazard sign should do one job.

## 4. Procedure

Procedure graphics can support:
- seal sequence;
- integrity failure response;
- dosimeter reference;
- helmet lock;
- filter connection.

Use large icons and short steps. Do not write lore essays.

## 5. Institutional character

Use sparingly:
- worker portrait;
- commissioning crew photo;
- current shift board;
- human-contribution morale graphic.

These should make the place feel human, not turn walls into graphic-design galleries.

## 6. Deletion test

For every sign, ask:

> If this sign disappeared, would navigation, safety, interaction clarity, or facility character become meaningfully worse?

If no, delete it.

## 7. Prohibited pattern

Do not repeat:
- CHECK;
- CONTROLLED;
- SAFE;
- TEST;
- OPERATIONS;
- INTEGRITY;

on multiple neighboring devices merely because those words sound industrial.
