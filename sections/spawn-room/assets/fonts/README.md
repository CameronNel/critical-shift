# HZ-01 lettering font

Unmodified DejaVu Sans Condensed Bold, from the executor's `fonts-dejavu-core`
package. Upstream: https://dejavu-fonts.github.io/. The bundled `LICENSE.txt`
contains the Bitstream Vera permission and notice; DejaVu changes are public domain.

The reference builder loads this copy so Linux and Windows rebuilds use the same
glyphs. Final labels are converted to mesh geometry and the native scene packs
its dependencies.
