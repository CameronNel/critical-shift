# Additional CC0 materials — tactile revision

All source images are original 2K JPG downloads from Poly Haven. They are released under [CC0](https://polyhaven.com/license): free to use without attribution requirements. Original URLs, published MD5 checks, SHA-256 checks, authors and physical dimensions are recorded in `tactile_manifest.json`.

| Material | Authored use |
|---|---|
| [Concrete Floor Worn 001](https://polyhaven.com/a/concrete_floor_worn_001) | Dry worn floor; scratches, aggregate loss, broad roughness |
| [Painted Plaster Wall](https://polyhaven.com/a/painted_plaster_wall) | Off-white trowelled wall and softer painted lower wall |
| [Metal Plate](https://polyhaven.com/a/metal_plate) | Localized threshold and kickplate tread, reduced rust colour |
| [Wood Table Worn](https://polyhaven.com/a/wood_table_worn) | Benches and worktop; subdued grain and residual finish |

Each includes diffuse, displacement and roughness. All 12 downloaded maps pass their published MD5 checks. Source images are unchanged; Blender shaders control palette, relief, roughness and mapping. Each used image is packed in the new .blend, with a relative fallback path to `cc0/`.

The earlier six maps and portrait sources remain documented separately. No marketplace assets, paid downloads or copied game assets are used.
