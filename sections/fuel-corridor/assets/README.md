# Original asset construction

The build creates the corridor shell, framed thresholds, sliding freight gate and service headers from original metric mesh construction. The source also authors a current single-cartridge carrier with saddles, restraints, casters and brakes; a workbench with forged tools and textile props; utility regulators, gauge, isolator, filter bowl and stored hose; electrical cabinets, first-aid case, work permits, lights, ventilation and route signs.

No geometry library or neighboring scene is imported. Asset assemblies remain editable and interactive door members are separated into rigid carriages. Physical props carry support anchors and collision-source metadata. Original generated T01/T02/T03 albedos live in art/materials and are packed in the .blend; no external texture downloads are required.
