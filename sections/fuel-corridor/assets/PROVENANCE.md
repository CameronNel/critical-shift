# Fuel overhaul source and material provenance

All new geometry is authored for this corridor in `blender/fuel_assets.py`,
`blender/fuel_details.py`, `blender/fuel_atmosphere.py` and `build_overhaul.py`.
The infrastructure details, cable paths, cloth hems, gauge numerals and local
fracture outlines are authored geometry; this pass adds no third-party props or
new external texture downloads. The task uses the repository's `spawn-room/blender/cozy_geo.py`
bmesh construction helpers; it does not import another room's prop meshes.

The material pass copies nine images already packed in the current spawn-room
portable module: diffuse, displacement and roughness images for
`wood_table_worn`, `painted_plaster_wall`, and `metal_plate`. Their upstream stored
paths identify them as the room's CC0 texture set. This task adds no external
texture download. The source module remains untouched. Copies are packed into the
new fuel module, with metre-scale UVs, restrained color mixing and relief.

DejaVu Sans is packed for signage. Its redistribution notices are preserved in
`fonts/LICENSE-DejaVu.txt`. No host font path is required when opening the scene.
Procedural material variation, geometry wear, text, service drawings and render
images are generated by the authored task scripts.
