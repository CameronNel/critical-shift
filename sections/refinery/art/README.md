# Look-development reference

This pass uses the current `design/ART_DIRECTION.md` from upstream commit `97bb68c` and the ongoing Spawn Room source/material family as read-only references. The occupied Spawn worktree is not a refinery dependency.

Visual principles: believable human scale, specific simplified machinery, controlled surface response, broad warm-grey/teal/charcoal grouping, contact shadows, practical light pools and sparse work clusters. No protected map or asset is reproduced.

Review evidence lives under `../production/renders/`. These are actual Blender renders, not concept images. Geometry and procedural materials remain editable in the `.blend` and source modules.
