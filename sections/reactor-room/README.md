# Reactor room

## Approved architectural layout

The current drawing revision is **P02**, approved for the detailed scene build. The reactor is centered in the octagonal hall; the compact Control room and observation window are centered along the east wall, reached by the small enclosed stair.

- [Five-sheet architectural PDF](architecture/output/reactor_compact_stair_architectural_set.pdf)
- [Editable millimetre CAD drawing](architecture/output/reactor_compact_stair_editable.dxf)
- [Drawing source, scales and validation](architecture/README.md)
- [Independent architectural review](architecture/SOL_REVIEW.md)
- [Current build status](production/TASK_STATE.md)

The drawing package includes ground/upper plans, all stair levels, sections, elevations, glazing and stair details. Archived P01 drawings are superseded.

## Detailed environment

The build follows [the scenery specification](scenery/reactorroom.md), the global art bible, and the brighter generated A02 reference selected by the user. Every mesh is authored from an empty scene. Ten fixed views and an independent Luna critic govern final visual acceptance.
