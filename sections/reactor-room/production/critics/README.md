Before formal review, define reactor-specific concerns for:
1. Spatial Readability
2. Stylized Art Direction
3. Materials / Anti-Plastic
4. Lighting / Atmosphere
5. Environmental Storytelling
6. Blender Technical Quality

Critics judge rendered evidence, not builder intent.


## Critic brief

Fresh critics must explicitly answer:
- does this look like a commercially released stylized PC environment;
- does it feel believable without becoming photoreal;
- is any object obviously a bevelled primitive pretending to be finished art;
- do materials read distinctly;
- is the reactor hero hierarchy clear;
- is signage/technical clutter excessive;
- does the room feel maintained and used;
- does any lighting or cyan emission flatten depth;
- does the scene resemble generic sci-fi or a web demo.

Critics should cite visible evidence from fixed-camera renders, not praise the scene based on intent.
