Use stable naming:
- cycle-01__<camera>.png
- cycle-02__<camera>.png

Do not change formal camera transforms casually after baselines are established.


## Review-render purpose

Review renders are diagnostic evidence. Include views that expose repetitive geometry, flat lighting, over-signage, material sameness, scale problems and clutter. Do not choose only flattering angles. Compare directly against the generated reactor reference plates.
