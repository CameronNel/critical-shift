## Production protocol

Any generated or imported section art/assets must remain compatible with the room's headless Blender source and ../../../design/AUTONOMOUS_SECTION_BUILD_PROTOCOL.md. Do not introduce hidden MCP-only dependencies or unrecorded external sources.


## Asset style constraints

Reactor assets must use believable construction and medium-complexity simplified geometry. Prefer reusable painted-metal, concrete, rubber, glass, fabric and restrained plastic families with low-frequency variation. Do not import a realistic industrial kit and simply desaturate it; do not build the room from primitive bevelled boxes either.

Any sourced asset must be restyled to the project material, proportion and detail-density rules before approval.
