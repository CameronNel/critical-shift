# Asset and material provenance

The original refinery module and current map/context geometry belong to the existing Critical Shift repository. Actual Spawn reference renders are repository artifacts used as a finish reference. New geometry, shaders, printed marks and prop details are authored procedurally in `blender/build_overhaul.py` and its numbered correction sources. No third-party asset or texture pack was imported. Most materials use physical-scale procedural color/roughness/grain; printed labels and contact wear are authored geometry/decals.

`art/refinery_direction.png` is a generated direction study, not an actual scene render or evidence of the finished Blender room. Acceptance views in `production/renders` are rendered from the actual checkpoint geometry.

Keep interactive source components separately named and keep the original shell/door interfaces unchanged. The formal camera manifest identifies fixed gameplay-height comparisons. Original world/map placement and required interfaces are preserved. The review-only context file uses existing linked map dependencies, omits map light objects, and is not a standalone distribution of the whole facility.
