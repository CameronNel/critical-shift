# R46 targeted shell-finish diagnostic

I opened the actual R45 and R46 images for C02_Casks and W04_CellService side by side. The finish reduces the broad smooth shell response, but overshoots into very high-contrast, soft-edged charcoal blotches. In C02, large irregular dark fields cover the lit fronts of both SC01 and SC02. In W04, a conspicuous cluster covers SC01, with a smaller matching read on the adjacent shell/support. The marks read as mold/stain or camouflage-like mottling across manufactured shells, rather than localized coating wear. I see no crisp edge that suggests a decal; the main issue is the soft stain/camouflage read.

This is a new material-art defect against R45 and would leave materials below 99 if carried forward unchanged. Equipment silhouettes, hardware, geometry and lighting appear otherwise unchanged in these two views. This is a targeted image diagnosis, not a full-cycle score or acceptance decision.
