# Immutable checkpoints

These are byte-exact source and recipe archives. Native blend snapshots retain links relative to the room directory where authored. To open a checkpoint, restore a copy to `compliance-dock/module_overhaul_R1.blend` in a separate checkout with the documented map dependencies hydrated. Do not overwrite the active source while review/render jobs run. The active deliverable is the room-root native file; checkpoint files are not standalone scenes at their archive location.
