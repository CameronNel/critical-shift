Large original JSON probes are stored in ordinary Git as lossless .json.gz payloads; decoded hashes/sizes are in large-probe-payloads.json. Original local probe bytes remain untouched. From this directory, `python3 -c "import gzip,pathlib; [p.with_suffix('').write_bytes(gzip.decompress(p.read_bytes())) for p in pathlib.Path('.').glob('*.json.gz')]"` restores exact report-referenced JSON filenames. This packages evidence only; no score or geometry changes.
