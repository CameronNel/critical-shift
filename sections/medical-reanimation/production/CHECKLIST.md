# Required-equipment and evidence checklist

Review scope: integration-ready Blender art section. Every independent category must be strictly greater than90. Final acceptance is recorded separately; this inventory alone is not approval.

| Requirement | Scene implementation | Evidence |
|---|---|---|
| Body/cart arrival | `main_entry`, opposed sliding leaves, southwest `BODY_CART` | Plan, opening rays, extraction and cart route sweeps, entry cameras |
| Gross decontamination | Rear alcove `DECON_WASH`,5m retractable reel, wand, shower, controlled drain and extract, used-PPE bin | Decon camera, apron state, route audit |
| Adult OCRU chamber | West `OCRU`, manufactured skid/frame/skins, segmented shutter, gasket/guide returns | Hero/pinch views, evaluated envelope |
| Body loading and transfer | `OCRU_BERTH`, lift columns, captive rails, slide/pivot `OCRU_TRANSFER_BRIDGE`, `CART_LIFT_DECK` | Staged transfer,12mm cushion step, measured surfaces and overlap |
| Suit service | `OCRU_SUIT_SERVICE`, lock collar, hose, parked coupling and retaining clip | Hero/route, hook anchor |
| Cartridge consumption point | Keyed receiver/drawer `OCRU_CARTRIDGE_RECEIVER` and capped stock | Hero/console/rear-service, host hooks |
| Physical restart | `RESTART_CONSOLE`, three guarded controls ARM/CONNECT/RESTART | Console view, plaque fit/obstruction audit |
| Monitoring | Two deliberately small status screens, employee glyph and process states | Console view, host state contract |
| Power and battery interface | `RESERVE_POWER`, hollow cabinet, supported battery trays, hinged service door; local isolation panel | Material/maintenance views, reserve-open state |
| Repair and service | Removable OCRU access panels, cabinet/console faces, reserved approaches, seal tools | Route sweeps and maintenance coverage |
| Consumable storage | Cartridge bank, glazed supply cabinet, supply bench/cartons/packs | Rear-service and supplies views |
| Recovery position | `RECOVERY_BERTH`, supported frame, fabric pad/pillow/blanket, release slip | Recovery view and egress route |
| Bureaucratic worker tone | Return-to-service notice, employee waiting display, shift log, property tag | Actual room/supplies views |
| Recoverable obstruction | Explicit transverse-body and longitudinal-cart bypass scenarios | Interaction JSON; staged bypass render |
| Exact external connections | One main_entry plus five capped utility interfaces | `interface.json`, `IF_*` readback |
| Independent review | Luna reviews actual pixels against approved generated concepts | `production/critics/`, rejected history preserved |
| Stable saved delivery | Saved-artifact measurement, live cold-open, two fresh-process fingerprints and independent factory-empty replay; pixel comparison and final acceptance recorded separately | Validation folder and final evidence manifest |

Runtime occupancy, state transitions, cartridge costs, power budgets, compliance behavior, multiplayer authority and ragdoll/navigation behavior are specified host responsibilities. They are not marked implemented by this artwork checklist.
