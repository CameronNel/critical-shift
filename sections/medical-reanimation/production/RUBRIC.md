# Independent integration-readiness rubric

Latest user acceptance: **strictly greater than90/100 in every relevant category**. A90 is still a failing score. Do not average categories or replace a visual judgment with a geometry check.

Independent Luna scores scale/circulation, shape/art direction, hierarchy/readability, materials, lighting, color discipline, environmental storytelling and technical correctness/evidence. The reviewer also records view-specific shortcomings against each camera's designated purpose. Required style is grounded Valorant with restrained industrial colors, tactile non-plastic material families, believable construction and purposeful lighting; teal/cyan is prohibited.

The gameplay specification supplies function. Existing Grok R09 supplies the inherited layout. Approved generated images supply visual guidance only; they cannot authorize dimensional changes or invented runtime features. Rejected images/reviews remain in the package.

Technical approval must inspect the saved file, measured geometry, exact interfaces, body/cart/carry clearances, obstructed-route scenarios, text/backing fit, physical contact evidence and a fresh cold-open render. This proves the owned art module to the stated bounds, not whole-map assembly, clinical engineering, runtime physics or networking.
