# Asset provenance

All current meshes, curves, type and procedural materials were authored from scratch by section-local Blender Python. No .blend/.fbx/.glb geometry from another facility section was imported. No external image textures, fonts or linked libraries are needed for the current slice. Blender's bundled font is used for modest diegetic labels.

Approved generated reactor references were inspected for rendering/material principles only; they were neither adopted as dock layouts nor sampled as texture assets. Human approval of a new generated reference was not requested or bypassed.
