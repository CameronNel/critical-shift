# Critical Shift

This repository is intentionally planning-only. Implementation, maps, prototypes, generated assets, and engine project files were removed so the project can be rebuilt cleanly from the design foundation.

## Planning documents

- [`GAME_SPEC.md`](GAME_SPEC.md) — master game design, systems, narrative, technical and validation specification
- [`docs/CANON.md`](docs/CANON.md) — setting and narrative canon
- [`docs/ART_DIRECTION.md`](docs/ART_DIRECTION.md) — authoritative visual direction
- [`docs/ENGINE_DECISION.md`](docs/ENGINE_DECISION.md) — current engine decision record and reopen conditions
- [`docs/REACTOR_ROOM_VISUAL_SPEC.md`](docs/REACTOR_ROOM_VISUAL_SPEC.md) — reactor hall functional and visual planning specification
- [`docs/ROADMAP.md`](docs/ROADMAP.md) — stage-gated production roadmap

No current map, playable implementation, engine project, or art asset should be treated as authoritative. Future implementation should be rebuilt from these documents.
