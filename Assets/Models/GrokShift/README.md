# Grok Shift Unity Environment

`GrokShiftEnvironment.fbx` is the Unity-native conversion of
`prototype/grok-shift/public/models/arrival.glb`.

The Blender conversion joins the static environment into one 7.3k-polygon mesh
with 23 material slots and removes the decorative `WorkCart*` meshes. The Unity
scene uses Critical Shift's authored physics cart and all existing runtime
systems in their place. The editable conversion source is
`art/blender/grok-shift-unity-source.blend`.
