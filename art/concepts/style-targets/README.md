# Style Targets

This directory is for **current Critical Shift visual-reference targets only**.

The former Sea of Thieves-based mine and reactor targets were removed when the project adopted the PEAK-led stylisation defined in [`../../../docs/ART_DIRECTION.md`](../../../docs/ART_DIRECTION.md).

## Rules

- PEAK is a reference for high-level stylisation, simplicity, silhouette readability, colour blocking, and low-detail 3D presentation.
- Do not place direct copies, extracted assets, or imitations of PEAK-specific characters, outfits, props, logos, locations, or textures here.
- New targets should depict original Critical Shift designs using simplified/faceted geometry, broad colours, restrained texture detail, and readable gameplay forms.
- Do not add Sea of Thieves painterly targets, photoreal references, realistic PBR targets, photogrammetry, or dense AAA environment concepts as active style targets.
- Reference images that exist only to study a specific technical fact should go under `../source-captures/` and must not override the art bible.
- If a target conflicts with `docs/ART_DIRECTION.md`, the target is obsolete and should be replaced or removed.
